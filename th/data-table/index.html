Data table

Data table แสดงข้อมูลเป็นแถวและคอลัมน์ (Carbon DataTable) ขับเคลื่อนด้วยข้อมูล คุณส่ง headers และ rows ให้ แล้วตารางจะเรียงลำดับ ค้นหา เลือก ขยาย และแบ่งหน้าให้ นอกจากที่ Carbon มี ยังซ่อนและตรึงคอลัมน์ ส่งออก CSV แก้ไขเซลล์ในตาราง และปรับความกว้างคอลัมน์ได้

resizable ใส่ที่จับที่ขอบท้ายของหัวคอลัมน์ทุกตัว ลากได้ หรือ Tab ไปแล้วใช้ปุ่มลูกศร (Shift เพื่อขยับทีละ 16px) header ที่มี resizable: false จะไม่มีที่จับ width, minWidth (ค่าเริ่มต้น 50) และ maxWidth กำหนดขอบเขต columnWidths เก็บความกว้าง และ ui-column-resize ยิงพร้อม { key, width, widths } หลังปรับแต่ละครั้ง เก็บ widths ไว้ใช้คืนค่าภายหลัง

ว่าง กำลังโหลด และ skeleton


ถ้าไม่มีแถว ตัวตารางจะบอกว่า "ไม่มีข้อมูล" ใส่ข้อความของคุณเองใน slot empty (emptyText) ถ้าค้นหาแล้วไม่เจอจะบอกว่า "ไม่พบข้อมูลที่ค้นหา" (slot no-results, noResultsText) loading คง toolbar และหัวตารางไว้ แล้วแสดงแถว skeleton (loading-rows) ขณะโหลดข้อมูลใหม่ ก่อนข้อมูลชุดแรกจะมาถึง ให้แสดง ui-data-table-skeleton แทนตาราง

Accessibility


    

  • ตารางเป็น <table> จริง ตั้งชื่อด้วย heading (หรือ label) คอลัมน์ที่เรียงอยู่มี aria-sort checkbox, radio และลูกศรของแต่ละแถวตั้งชื่อด้วยเซลล์แรกของแถว ("เลือกแถว, สัญญาบริการ")
    • 

  • สถานะแบบ polite บอก "เรียงตามคอลัมน์ สัญญา จากน้อยไปมาก" หลังกดเรียง และ "แสดง 3 จาก 12 แถว" เมื่อหยุดพิมพ์ค้นหา แทนที่จะอ่านทั้งตารางใหม่แบบ <tbody> ที่เป็น live region ของ Carbon
    • 

  • ขณะ loading ตารางเป็น aria-busy จำนวนในแถบ batch เป็น status จำนวนใหม่จึงถูกอ่านเมื่อเลือกแถว
    • 

  • grid ที่แก้ไขได้ทำตามแบบ grid ของ WAI-ARIA: เซลล์ที่แก้ไม่ได้เป็น aria-readonly และเซลล์ที่แก้ได้บอกว่า "กด Enter เพื่อแก้ไข"
    • 



ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Data table
